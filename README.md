# Snake Game en Python

Un juego clásico de Snake implementado en Python usando pygame.

## Requisitos

- Python 3.6 o superior
- pygame

## Instalación

1. Instala las dependencias:
```bash
pip install -r requirements.txt
```

## Cómo jugar

Ejecuta el juego con:
```bash
python snake.py
```

### Controles

- **Flechas del teclado**: Controlan la dirección de la serpiente
  - ↑: Arriba
  - ↓: Abajo
  - ←: Izquierda
  - →: Derecha
- **ESC**: Salir del juego
- **ESPACIO**: Reiniciar después de Game Over

### Objetivo

- Come la comida roja para crecer y ganar puntos
- Evita chocar con las paredes
- Evita chocar con tu propio cuerpo
- ¡Consigue la mayor puntuación posible!

## Características

- Gráficos simples y coloridos
- Sistema de puntuación
- Cuadrícula visual
- Prevención de giros de 180 grados
- Reinicio rápido con la barra espaciadora
